# 🎵 Songs Player (v1.0.1)

A high-fidelity online streaming and offline music player built with AndroidX Media3 (ExoPlayer), Material You Dynamic Colors, and Room Database.

## 📖 Comprehensive Documentation
👉 For complete feature breakdown and user instructions, see **[APP_FUNCTIONALITY.md](file:///d:/_test/song_player/APP_FUNCTIONALITY.md)**.

## ✨ Highlights
- **4 Main Tabs:** Online (Trending, Quick Play, Search), Artists, Offline (Tracks, Albums, Playlists, Genres), Device Explorer.
- **Audio/Video Downloader:** Download online tracks as high-quality **MP3 audio** or **MP4 video clips** directly to local storage.
- **5-Band Equalizer:** Custom frequency sliders, genre presets (Pop, Rock, Classical, Jazz, Heavy Metal, etc.), Bass Boost, 3D Virtualizer, and Loudness Enhancer.
- **Sleep Timer:** Automatic audio fadeout and sleep timers (15 to 90 mins).
- **Controls & HUD:** Persistent mini player, animated rotating artwork, tempo speed control (0.5x to 2.0x), shuffle, and repeat modes.
- **Settings:** Material You dynamic colors, gapless playback, crossfade, audio quality picker, cache cleaner.
- **Distribution:** Download APK directly to public Downloads folder, Share APK via FileProvider, and Developer Feedback.
